# Ankit Kumar's Personal Website

A clean, static website showcasing academic work and research.

## Features

- **Static HTML**: No compilation needed - just pure HTML and CSS
- **Modern Design**: Clean, responsive layout with modern CSS
- **Fast Loading**: Optimized for performance
- **Mobile Friendly**: Responsive design that works on all devices

## Structure

- `index.html` - Main website content
- `css/style.css` - Modern styling
- `me.jpeg` - Profile photo
- `stuff/` - PDFs and documents

## Development

Simply edit `index.html` and `css/style.css` directly. No build process required!

## Deployment

The site is ready to deploy as-is to GitHub Pages or any static hosting service.
